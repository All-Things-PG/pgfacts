# Knowledge Base

The Knowledge Base is the planned searchable collection of trusted Pyoderma Gangrenosum information, resources, and opportunities. It is intended to help patients, caregivers, providers, and other visitors find relevant information based on their needs.

The detailed content model and how the Knowledge Base fits into DCMS are described on the [DCMS Knowledge Base page](/dcms/knowledge-base/).
