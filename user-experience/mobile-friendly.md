# Mobile Friendly

All Things PG should remain clear, readable, and easy to use on phones and tablets as well as desktop screens.

Mobile-friendly design includes responsive layouts, readable text, touch-friendly controls, accessible navigation, appropriately sized images, and content that remains useful without requiring a wide screen. These considerations should be included as new pages, menus, forms, and knowledge-base features are developed.
